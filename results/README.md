# Public analysis sources and aggregate outputs

This directory retains analysis implementation, historical methodological reports, current numerical revision history and two frozen aggregate CSV tables. The complete record-level evidence is preserved outside the public tree in the editorial store. Historical report descriptions of the earlier full snapshot are not claims that all of their inputs are now public.

The retained condition_question_macro.csv and condition_and_stratum_tables.csv supply the aggregate checks used by current_release/validate_release_alignment.py. Additional historical aggregate tables are under ../analysis_support/tables/. Current figure inputs are under ../paper_figures/source_data/. Their values were not changed by the rights review.

Historical builders can write neighboring files and require private inputs. Do not run them in this tree as if they were supported reproduction commands. verify_snapshot.py and verify_original_archives.py apply to the full private snapshot. Public verification commands are listed in the root README.

Full checkpoints, selected-observation messages, question-evidence snapshots, candidate and final annotation records, and audit explanations quoting source/claim text are editorial-only in the present distribution. This is a release decision pending rights work, not a finding that each record is legally prohibited from being shared. See ../THIRD_PARTY_NOTICES.md.
