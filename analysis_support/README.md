# Technical aggregate tables

The 20 CSV files in [tables](tables/) retain historical aggregate results without changing their numerical contents. Filename prefixes are stable historical table identifiers, not a document outline. [Source index](SOURCE_INDEX.md) resolves the retained inputs; [provenance](table_provenance.json) records selections and historical source hashes. Source paths in the JSON are relative to the repository root.

A1 records execution cells. C1–C5 contain terminal views, paired differences, uncertainty and observed/expanded counts. D files contain node/edge estimates, denominators and grouped comparisons. E files contain audit allocation, agreement and bounds. CSV headers define the retained fields; rates in the historical sources may be fractions rather than percentages. Check each source schema before comparison.

These are historical estimates, not the current author-revised display values. Current inputs and their version boundary are documented in [current release](../results/current_release/README.md). Source hashes predating English localization are lineage identifiers, not claims of equality to current distributed bytes. No document or image is required to read these files.
